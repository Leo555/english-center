# 🚀 Power Up 小英雄 —— 分级单词句子闯关学习游戏

一款配合剑桥《Power Up》教材分级体系设计的儿童英语单词/句子学习应用。用 **图形选择、连线配对、消消乐** 三种小游戏寓教于乐，配合 **学习模式 + 通关模式 + 错题智能巩固**，帮助孩子在游戏中巩固 Power Up 教材内容。

## 一、设计依据：Power Up 分级机制

| 级别 | 适龄 | CEFR | 对应剑桥考试 | 目标词汇量 |
|---|---|---|---|---|
| Power Up 1 | 6岁 | Pre-A1 | YLE Starters | 300 |
| Power Up 2 | 6-7岁 | A1 | YLE Movers | 600 |
| Power Up 3 | 7岁 | A2 | YLE Flyers | 800 |
| Power Up 4 | 7-8岁 | A2 | Pre-KET | 1000 |
| Power Up 5 | 8-9岁 | A2-B1 | KET | 1300 |
| Power Up 6 | 9-12岁 | B1 | PET | 1600 |

每个级别 **9 个单元**，每单元一个生活主题（颜色、家人、动物、职业……），第 9 单元为复习单元。应用的关卡地图与教材单元一一对应，孩子可以按教材学习进度同步闯关巩固。

> `src/data/levels.ts` 中 **Power Up 1**（27 个小单元 / 约 300 词）、**Power Up 2**（9 个单元 / 约 108 词）已填充完整的可游玩示例词表（含音标、emoji 图形、例句、单元主题 logo）；**Power Up 3-6** 保留了官方分级参数与单元主题骨架（`words: []`），方便后续接入真实教材词表（见下方"如何扩充词库"）。

## 二、核心玩法

### 1. 学习模式（无压力认知）
`LearnMode`：翻卡式学习，正面显示图形+单词+音标，点击卡片翻转显示中文释义+例句，一键 TTS 发音（浏览器原生 Web Speech API，无需音频素材/联网）。完成一个单元的学习后解锁该单元的三种闯关游戏。

### 2. 通关模式（三种游戏 + 关卡地图）
- **🎯 图形选择**：看词选图 / 看图选词，随机切换方向，四选一。
- **🔗 连线配对**：单词与图形一一点击配对（移动端友好的"点选连线"），一次最多 6 组，分批完成。
- **💥 消消乐**：单词卡与图形卡混排成网格，点击配对成功即消除，支持连击（combo）计数。

每关根据答题正确率评 1-3 星；单元累计获得一定星数即"通关"，解锁下一单元；一个 Power Up 级别全部单元通关后解锁下一级别 —— 形成完整的闯关地图体验。

### 3. 错题智能巩固（🧠 巩固练习）
任何模式下答错的词都会自动进入"错题本"，采用 **简化莱特纳（Leitner）间隔重复算法**：
- 答错 → 打回第 1 格，当天即可再次复习；
- 答对 → 进入下一格，复习间隔按 1/2/4/7 天递增；
- 连续在最高格答对 → 视为掌握，移出错题本。

首页"巩固练习"入口会显示当前到期需要复习的词汇数量，孩子可任选一种游戏玩法针对错题进行专项强化，形成"学习 → 闯关 → 犯错 → 巩固 → 再闯关"的记忆闭环。

## 三、技术实现

- **技术栈**：React 18 + TypeScript + Vite + Tailwind CSS + Zustand（状态管理与本地持久化）
- **数据安全**：纯前端本地存储（`localStorage`），无网络请求、无用户隐私数据，符合儿童应用最小化数据收集原则
- **发音**：使用浏览器内置 `SpeechSynthesis`，无需第三方音频资源
- **视觉素材**：全部使用 emoji 作为图形化词汇表示，零图片资源依赖、加载快、离线可用

### 运行方式
```bash
npm install
npm run dev      # 本地开发预览
npm run build    # 生产构建
```

## 四、如何扩充词库（接入 Power Up 3-6 真实教材内容）

编辑 `src/data/levels.ts`，仿照 L1/L2 的写法为对应单元填充 `words` 数组，每个词条通过 `w(en, cn, ipa, emoji, exampleEn, exampleCn)` 辅助函数创建：

```ts
w('elephant', '大象', '/ˈelɪfənt/', '🐘', 'The elephant is big.', '大象很大。')
```

将 `placeholderUnits(...)` 里对应单元替换为 `unit('L3', 1, '校园生活', 'School Life', [ ...words ])` 即可，无需改动任何游戏/学习/复习逻辑，三种小游戏与巩固练习会自动支持新内容。
